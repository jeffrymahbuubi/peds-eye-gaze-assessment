Do Calibration: runs a fresh calibration against the connected tracker using the point count/show-window controls above. Load Calibration File: file picker over a saved calibration.json; hard-errors if its subject_id doesn't match the Subject ID field above — same check the existing --calibration-file CLI flag already performs.
